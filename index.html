ScryPlay

Sports analytics and prediction platform at scryplay.com

ScryPlay predicts match outcomes and goal distributions for sports like soccer, and shows them as probabilities. I built it from the first data pull to the model results.

What I did

  • Engineered features and trained ensembles (XGBoost, Random Forest) alongside Elo ratings. For low-scoring games like soccer I paired a Dixon-Coles Poisson model with XGBoost.

ScryIQ

AI agent for document intelligence at scryiq.com

ScryIQ is an Agentic RAG service for enterprise document intelligence. It answers questions about a user's own documents, and only from what those documents say.

What I did

  • Built the agentic RAG service on Azure OpenAI, LlamaIndex and LangChain, with embeddings, retrieval pipelines and tool-based workflows.
  • Built the upload API that saves each file to Azure Blob Storage.
  • Used Azure Document Intelligence to extract the content, and stored the text and metadata in Azure Cosmos DB.
  • Used Azure Cosmos DB as the Vector DB store as well, with chunking and embeddings, so one database holds everything.
  • Designed a top-level agent that breaks down the question and worker agents that fetch the relevant chunks (LlamaIndex).
  • Wrote strict prompts to keep answers grounded and cut down hallucination.

Extended technical scope & domain exploration:

  • Evaluated and designed proof-of-concept workflows using Azure AI Services for Named Entity Recognition (NER), word cloud frequency analysis, handwritten text recognition (OCR), and person detection.
  • Sentiment Analysis built into the system to provide emotional context to the document analysis.

Growing into an Enterprise Document Intelligence platform. Answers stay tied to the source document.
